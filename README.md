# Decodelab Project 4 - Serverless Cost Calculator

## 📌 Project Overview

This project demonstrates a simple serverless Cost Calculator built using
AWS Lambda and Python.

The Lambda function accepts two numbers as input, calculates their sum,
and returns the result in JSON format.

Amazon CloudWatch is used to monitor and verify the Lambda function execution.

## 🎯 Project Objective

The objective of this project is to:

- Create an AWS Lambda function using Python
- Accept two numbers as input
- Validate the input values
- Calculate their sum
- Return the result in JSON format
- Monitor Lambda execution using Amazon CloudWatch

## 🛠️ Technologies Used

- AWS Lambda
- Python
- Amazon CloudWatch
- AWS IAM
- JSON
